# MERN AI Task App

A full-stack MERN application that performs AI-style text processing operations.

## Features
- JWT Authentication
- Uppercase Conversion
- Lowercase Conversion
- Reverse Text
- Word Count
- Task History
- Responsive UI

## Tech Stack
- React.js
- Node.js
- Express.js
- MongoDB
- JWT

## Installation

### Frontend
cd frontend
npm install
npm run dev

### Backend
cd backend
npm install
node server.js
